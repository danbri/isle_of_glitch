Mazeballs — run analytics

Population and development over an evolutionary run, read from the committed generation archives (runs/archive/gen-*.json). Each archive keeps one representative per lineage — chosen for rarity, not typicality — sampled every few generations, so these are trends across representatives, not a full census.
