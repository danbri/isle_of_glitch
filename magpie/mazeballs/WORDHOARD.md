# Word-hoard — Uncleftish Beholding names for the world

Plain-rooted English for the machinery, after Poul Anderson's *Uncleftish
Beholding* (atomic theory written with Germanic roots only). Not decoration: the
naming discipline is a check on the First Law. A borrowed Latin word can smuggle in
a whole conclusion — "predator" names a role the world is supposed to *discover* —
whereas a built-from-parts word has to say what the thing actually does. If a name
cannot be built plainly, that is usually a sign it is a story rather than a
mechanism.

Coined by the human; recorded here so usage stays consistent.

## Life-stuff and heredity

| word | means |
|---|---|
| **lifestuff** | the cell's internal coding matter; our stand-in for DNA/RNA and proteins, kept cartoon (see `CELLS.md`) |
| **lifeling** | a single living unit — one cell, the smallest thing that is alive |
| **liferoom** | the space a lifeling occupies and works within; its extent and its immediate surrounds |
| **skinwall** | the boundary between inside and outside — membrane, and the thing that makes an inside exist at all |
| **kinwriting** | the heritable text itself; what is copied at a birth event (our genome) |
| **kinmark** | one heritable trait or tag; a readable mark carried by kin (a locus, an adhesion tag) |
| **tidings** | signalling between lifelings — what is sent, not the sending (chemical, mechanical, neural) |
| **lifeweb** | the whole ecosystem: everything alive plus what it lives on and off |
| **lyf-gang** | one cell assembly — the creature-ish thing a uid names, whether or not it is still in one piece |

## Suggested additions — evo-devo

Development is where borrowed words do the most damage, because "morphogen" and
"gradient" and "body plan" all sound like explanations.

| word | means |
|---|---|
| **unfolding** | development itself — kinwriting becoming a body, in time, able to fail |
| **shapewrit** | the developmental map: how position in the egg becomes a cell's properties |
| **motherdrift** | the maternal gradient laid down in the egg; the axis unfolding reads |
| **headward / tailward** | our two poles, instead of anterior/posterior |
| **backward / bellyward** | the cross axis, instead of dorsal/ventral |
| **budding** | reproduction as a process — the propagule leaving, with yolk, able to die |
| **eggroom** | the contained chamber where unfolding happens; the reason gradients survive |
| **kinsplit** | one birth event; the thing an assembly uid names |
| **likeness** | how far two bodies resemble each other — measured, never assumed from kinwriting (twins are not one animal) |

## Suggested additions — physics and world

| word | means |
|---|---|
| **grit** | purchase the ground offers — already in use, already plain |
| **grabbiness** | how hard a lifeling holds on — already in use |
| **stickiness** | adhesion to substrate rather than to kin |
| **grain** | which way the ground slips easily; anisotropy of the substrate |
| **stream** | the flow field; the medium's own motion |
| **sunfall** | the fixed energy inflow — what makes it a boundary condition and not a purse |
| **standing crop** | mote stock; what is there to be eaten right now (already in use) |
| **drawdown** | grazing a patch below what it had; the thing that should make moving pay |
| **shove** | contact repulsion; volume exclusion |
| **holdfast** | a bond between lifelings — sinew and bone are stiffnesses of one holdfast |
| **swaystuff / stiffstuff** | the compliant and rigid ends of holdfast material, instead of sinew/bone |
| **heat** | where lost energy goes, and it must always go somewhere |

## Where NOT to use plain words

Naming the *mechanism* plainly is good. Naming an *outcome* plainly is the same
error in a nicer coat: "hunter" is no better than "predator". Outcomes stay
descriptive and measured — a lifeling with high grabbiness, a body whose muscle
fraction rose — never a type the kernel branches on.
