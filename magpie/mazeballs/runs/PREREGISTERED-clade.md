# Pre-registered, written before the run (2026-08-07)

**H2.** The clade-race interaction survives independent replication at deep time.

    excess = mixedShare(284) - predictedFromSoloGrowth   >   2 x SE   at 40k steps

Discovery run: excess +0.0845 +-0.0220 (2SE 0.0440), seeds 700+rep*37, 4 reps.
This test uses seeds 40000+rep*37 and 5 reps. The discovery run generated H2 and
is NOT pooled into it.

**H3 (dominance).** The interaction is not carried by the geography. Running the
same race with the geography flattened should leave the excess intact. If the
excess collapses without geography, the effect is a conjunction and the biotic
channel is not dominant on its own.

**Falsifiers.** H2: excess <= 2 SE, or fewer than 4 usable replicates.
H3: excess without geography differs from excess with it by more than their
pooled SE in either direction.

**Why this design.** The monoculture control already holds the world constant
between mixed and alone, so the excess is purely attributable to the other clade.
What it does not do is weigh that against an abiotic factor, which is what
"dominant" requires. The flat-geography arm supplies that comparison.
