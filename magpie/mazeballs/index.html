Population file

Nothing here survives a reload. Export writes the whole population — genomes, generation count, lineage record, gain, and the field layout — to a file you can load back later. Because the layout travels with the genomes, an imported population is scored on exactly the world it evolved in, so two settings can be compared on identical genomes rather than merely similar ones.

Console

Everything is live on window.evoDevo — sim, renderer, CFG, world(), conditions. The population's tensors are tf.Variables, so e.g. await evoDevo.sim.fitness.data() or await evoDevo.sim.populationStats() work straight from devtools.
